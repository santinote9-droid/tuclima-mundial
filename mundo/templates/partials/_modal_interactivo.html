{% comment %} ========================================================================== BLOQUE INTERACTIVO REUTILIZABLE PARA VENTANAS MODALES (agro / naval / aereo / energia) Cada modal que quiera "Personalizar / Alerta / Notas / Exportar" agrega dentro de su .modal-content un elemento con clase tc-interactivo y estos data-atributos: data-sector = "agro" | "naval" | "aereo" | "energia" data-modal = "modGDD" (el mismo id del modal) data-lat / data-lon data-campos = JSON array de campos de personalización, ej: [{"key":"cultivo","label":"Mi cultivo","tipo":"cultivo"}, {"key":"fecha_siembra","label":"Fecha de siembra","tipo":"date"}] (opcional — si se omite no se muestra la sección) data-alerta = JSON con la variable a la que aplica la alerta, ej: {"variable":"vpd","label":"VPD","unidad":"kPa"} (opcional — si se omite no se muestra la sección) data-notas = "0" para desactivar la bitácora (por defecto está activa) Este archivo se incluye UNA sola vez por página. Además, cada página debe llamar a window.tcInteractivoAlAbrir(modalId) dentro de su función openModal(id) existente, para cargar los datos la primera vez que el usuario abre ese modal puntual (carga perezosa). ========================================================================== {% endcomment %}
