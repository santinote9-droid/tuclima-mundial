# TuClima Pro · Agro
### Clima operativo para asesores que deciden con datos

**Para:** grupos CREA · Aapresid · deptos. técnicos de cooperativas (AFA / ACA)

---

## El problema
El asesor mira 4–5 fuentes distintas (modelo, radar, estación, WhatsApp del campo) y pierde tiempo armando un criterio común para varios lotes. La decisión de siembra, riego o pulverización queda a intuición cuando faltan índices claros.

## Qué es TuClima Pro (modo Agro)
Una pantalla por función — no un dashboard genérico — pensada para el ingeniero agrónomo:

| Función | Qué ve el asesor |
|---------|------------------|
| **Operación** | Semáforo y tendencia 24 h en el punto |
| **Radiación** | GHI, PAR (fotones), Air Mass / Beer–Lambert, balance Rn → agua evaporable |
| **Climatología** | Anomalías, ENSO, climograma, **SPI / SPEI** |
| **Circulación Hemisférica** | Eddies, **storm tracks**, chorro (U) |
| **Estadística** | Boxplot, frecuencias, tests para reportes |

## Ángulos por organización

**CREA** — “El mismo criterio climático para los 12 campos del grupo.”  
Mostrar: Climatología + SPI (sequía a 3 y 6 meses) en un lote representativo.

**Aapresid / Chacras** — “Radiación y balance de suelo, no solo ‘va a llover’.”  
Mostrar: GHI/PAR, Rn (onda corta vs larga), albedo y mm evaporables.

**AFA / ACA** — “Ventanas operativas a escala cooperativa.”  
Mostrar: storm tracks + operabilidad (pulverización / siembra) para coordinar cuadrillas.
